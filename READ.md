# Sunshine – Frontend

The frontend of our project, built using React. It provides the user interface and allows users to interact with the system.

## Technologies Used

* React
* JavaScript
* CSS

## Installation and Setup

1. Clone the repository.

2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open the local URL displayed in your terminal.

## Backend

This frontend connects to the Laravel backend through API requests.
